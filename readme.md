# Cannon Game

Aplicativo Android desenvolvido com base no projeto **Cannon Game**, apresentado no livro *Android 6 for Programmers: An App-Driven Approach*, 3ª edição.

O projeto consiste em um jogo desenvolvido para a plataforma Android, utilizando os conceitos e as técnicas de programação apresentados na obra como referência para sua implementação.

## Autor

**Luan Pereira Barbosa**

## Tecnologias utilizadas

- Android
- Android Studio
- Java

## Como executar

1. Clone ou baixe este repositório para sua máquina.
2. Abra o **Android Studio**.
3. Selecione a opção **Open** e escolha a pasta do projeto.
4. Aguarde a sincronização e a configuração do Gradle.
5. Conecte um dispositivo Android ou inicie um emulador.
6. Clique em **Run** para compilar e executar o aplicativo.
